Model Evaluation & Benchmark Report

Comprehensive empirical performance analysis across training epochs, inference hardware substrates, and quantization profiles.

Executive Summary

This report documents validation convergence, inference latency characteristics, and hardware efficiency for the DeepScale-v4 transformer architecture across 5 training epochs. Empirical results confirm monotonic convergence with zero loss divergence across distributed data-parallel workers.

Validation accuracy

Held-out validation accuracy rises from 72% at epoch 1 to 94% at epoch 5 under cosine learning rate decay with linear warmup.

Convergence & Hyperparameter Dynamics

The optimization pipeline utilizes decoupled weight decay (AdamW) with gradient clipping at 1.0 norm threshold:

  • Initial Learning Rate: 3.5e-4 with 2,000 warmup steps
  • Weight Decay: 0.05 applied strictly to non-bias weights
  • Effective Batch Size: 2,048 sequences with FlashAttention-3 kernels
  • Cross-Entropy Validation Loss: Decreased from 2.84 to 0.41 nats/token

Inference latency

Median latency for model variants A (FP16 baseline), B (INT8 quantized) and C (INT4 AWQ) is 18, 24 and 31 ms on edge hardware.

Hardware Utilization & Throughput Benchmark

Benchmarked across unified memory architectures and dedicated accelerator clusters at concurrency 32:

  • Apple Silicon M-Max (Unified LPDDR5): 142 tokens/sec per stream at 18W power envelope
  • NVIDIA H100 SXM5 (80GB HBM3): 1,180 tokens/sec sustained at batch size 64
  • KV-Cache Memory Footprint: 1.2 GB per 8k context window under PagedAttention allocation
  • First-Token Time (TTFT): 42 ms median at 4,096 prompt prefix length

Production Deployment Verification

Final acceptance criteria verified for edge deployment: memory footprint remains strictly within the 16 GB unified RAM boundary, zero numerical divergence observed between torch.compile and ONNX Runtime execution graphs.
